# Questions for Experts

## Portfolio / research calibration

- Which artifacts most reliably show that a junior researcher understands a security problem rather than merely summarizing it?
- For threat-modeling projects, what minimum evidence makes the analysis technically credible?
- When is a benchmark more valuable than building another security agent/tool?
- What separates useful attack-surface taxonomy from arbitrary categorization?
- Which claims should require reproduction/code-level verification before being presented as findings?

## Technical calibration

- How should exploitability, severity, and production applicability be separated when direct reproduction is unavailable?
- What is a reasonable stopping condition for a student-led deep dive?
- Which false-positive/false-negative trade-offs matter most in security tooling evaluation?
